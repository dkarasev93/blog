## СЕНСАЦИЯ ПЕРВАЯ: БЛИЗНЕЦЫ, КОТОРЫМ ВЕЛЕНО ИСЧЕЗНУТЬ, СЛУЖАТ ПО СЕЙ ДЕНЬ

В делопроизводстве `mytoncore/utils.py`, на строках 50 и 70, разбирательство обнаружило двух сотрудников-близнецов. Первая особа:


## СЕНСАЦИЯ ВТОРАЯ: ПОЧТАМТ ОПУСКАЕТ ОДНО ПИСЬМО В ТРИ ЯЩИКА

Улика из `mytoncore/mytoncore.py`, строки 831–837, — функция `SendFile`, отправляющая сообщения в сеть:

```python
self.liteClient.run("sendfile " + file_path)
if duplicateSendfile:
    try:
        self.liteClient.run("sendfile " + file_path, use_local=False)
        self.liteClient.run("sendfile " + file_path, use_local=False)
    except Exception:
        pass
```

Разбирательство показало: одно и то же письмо опускается в почтовый ящик трижды — сперва по месту жительства, потом ещё два раза подряд, для верности, через публичных лайтсерверов. Имя настройки честное — `duplicateSendfile`, — но дважды, а не трижды; куда подевался честный `triplicate`, установить не удалось. А протокол происшествия не ведётся вовсе: `except Exception: pass`. Дойдёт письмо или нет — почтамт узнает последним, то есть никогда.

## СЕНСАЦИЯ ТРЕТЬЯ: СПРАВОЧНИК, ОТВЕЧАЮЩИЙ НА ЛЮБОЙ ВОПРОС МОЛЧАНИЕМ

В `mypylib/mypylib.py`, строки 62–66, обитает существо по имени `Dict` — словарь, желающий казаться джентльменом с атрибутами:

```python
def __setattr__(self, key: str, value: Any) -> None:
    self[key] = value

def __getattr__(self, key: str) -> Any:
    return self.get(key)
```

Механика изящна и зловеща: обратись сыщик по ошибочному имени — скажем, `status.is_wrkng` вместо `status.is_working`, — и вместо законного окрика `AttributeError` справочник вежливо вернёт `None`, будто так и надо. На этом молчаливом фундаменте покоится весь главный фолиант `mytoncore.py` в 2806 строк, где объекты `Dict()` плодятся на каждой странице. Опечатка в таком доме не шумит — она тихо садится в углу и ждёт выборов.
