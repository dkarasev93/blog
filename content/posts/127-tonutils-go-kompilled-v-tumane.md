# ВЕЧЕРНИЙ ВАЛИДАТОР

*Газета газовых фонарей, пыльных мемпулов и бессонных нод*

## ДЕЛО О СЛОВЕ, КОТОРОЕ НЕ ПРОШЛО СБОРКУ

Лондон тонул в тумане, когда сыщик «Вечернего Валидатора» получил папку из [xssnick/tonutils-go](https://github.com/xssnick/tonutils-go). Контора работает с TL-схемами: читает структуры, раскладывает поля по ячейкам и собирает их обратно для дел тонкой сетевой службы.

Газовый рожок кашлянул уже на первой странице. В машинном подвале нашли не один случайный промах, а целую систему вывесок: компиляция там именуется `compilled`, единственный флаг назван `singe`, а ошибка сборки сетевого письма сообщает, что его не удалось *filed*.

Сыщик не стал выносить приговор по одному пропущенному `i`. Но когда одна и та же клякса стоит в четырех рабочих сообщениях, а рядом живет отдельное `singe`, дело перестает быть опечаткой и становится стилем учреждения.

## МЕСТО ПРОИСШЕСТВИЯ

След ведет в [коммит 219b7ae](https://github.com/xssnick/tonutils-go/commit/219b7aed1887395577de44277917e1f51a53e177), в файл [tl/precompile.go](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/tl/precompile.go). В [строках 62–65](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/tl/precompile.go#L62-L65) контора проверяет описание поля:

```go
			if len(tags) != 2 {
				panic("field can only contain singe flag")
			}
```

Цитата дословная. Флаг может быть только один, но в протокол это попало как `singe`. Ошибка живет в `panic`, то есть не в музейной записке и не в комментарии, а в аварийном сообщении механизма, который разбирает TL-описания.

Далее вывеска повторяет свой подвиг. В [строке 334](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/tl/precompile.go#L334) появляется:

```go
				return reflect.Value{}, fmt.Errorf("tl type %s is not compilled", val.Type().String())
```

А в [строках 469–471](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/tl/precompile.go#L469-L471) та же формула встречает сыщика при сериализации структуры:

```go
	if si == nil {
		return fmt.Errorf("tl type %s is not compilled", rv.Type().String())
	}
```

Слово `compiled` так и не добралось до лондонской типографии. Контора не просто один раз ошиблась в письме: она размножила одну и ту же форму в разных входах своей машины.

## ТРИ ДВЕРИ, ОДНА ВЫВЕСКА

В [строках 481–489](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/tl/precompile.go#L481-L489) тот же текст сторожит уже путь `appendStruct`:

```go
	if si == nil {
		return nil, fmt.Errorf("tl type %s is not compilled", rv.Type().String())
	}
```

И наконец, в [строках 599–604](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/tl/precompile.go#L599-L604), он встречает читателя на входе обычного разбора:

```go
	case reflect.Struct:
		info = _structInfoTableByType[srcE.Type()]
		if info == nil {
			return nil, fmt.Errorf("tl type %s is not compilled", srcE.Type().String())
		}
```

Вот почему это не просто английская опечатка. Слово расползается по трем маршрутам: отражение значения, сериализация и разбор. В каждой двери стоит один и тот же швейцар, одинаково уверенный, что `compilled` — официальный термин. Если библиотека возвращает эту ошибку пользователю, тот получает не только причину отказа, но и маленький урок о том, как в тумане рождаются новые языки.

Сыщик, впрочем, не утверждает, что именно эта буква ломает работу. Доказано лишь то, что сообщение об ошибке будет выглядеть одинаково на нескольких путях и что текст пережил свежий коммит [219b7ae](https://github.com/xssnick/tonutils-go/commit/219b7aed1887395577de44277917e1f51a53e177). Поломка механики и поломка английского — разные преступления, хотя в одном подвале они часто снимают одну комнату.

## ТЕЛЕГРАФ СООБЩАЕТ: `FILED`

В соседнем отделе, где [xssnick/tonutils-go](https://github.com/xssnick/tonutils-go) строит сетевые сообщения, найден второй свидетель. Файл [adnl/adnl.go](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/adnl/adnl.go), [строки 1188–1191](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/adnl/adnl.go#L1188-L1191):

```go
			if err != nil {
				return nil, nil, fmt.Errorf("filed to build message part %d, err: %w", i, err)
			}
```

И в [строках 1204–1207](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/adnl/adnl.go#L1204-L1207) телеграф повторяет донесение для целого письма:

```go
	if err != nil {
		return nil, nil, fmt.Errorf("filed to build message, err: %w", err)
	}
```

Здесь уже нет оправдания внутренним именем поля. Ошибка выходит наружу через `fmt.Errorf` и может попасть в журнал клиента или к человеку, который пытается понять, почему сообщение не собралось. Вместо `failed` ему предлагают загадочный глагол `filed`: будто письмо не потерпело неудачу, а было аккуратно подшито в архив.

## ПРИГОВОР СЫЩИКА

[Коммит 219b7ae](https://github.com/xssnick/tonutils-go/commit/219b7aed1887395577de44277917e1f51a53e177) из [xssnick/tonutils-go](https://github.com/xssnick/tonutils-go) оставил в рабочей библиотеке маленькое царство новых слов. В [tl/precompile.go](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/tl/precompile.go) флаг стал `singe`, компиляция — `compilled`, а в [adnl/adnl.go](https://github.com/xssnick/tonutils-go/blob/219b7aed1887395577de44277917e1f51a53e177/adnl/adnl.go) неудача сборки превратилась в `filed`.

Сеть от этих букв не рухнет. Но сообщение об ошибке — часть инструмента так же, как ключ и проверка длины. Когда один и тот же промах занимает четыре двери, а соседний отдел добавляет еще два, сыщик обязан записать: в конторе завелся не баг, а диалект.

Газовый рожок пробил полдень. Лондон снова накрыло туманом, и где то в нем `compiled` безуспешно ищет потерянную букву.
