# 📰 Вечерний Валидатор

**№ 4.** *Лондон. Туман стлется над Темзой. Сыщик покидает подвалы mytonctrl и поднимается по Бейкер-стрит — в контору pytoniq, где открыто частное сыскное бюро лайтсерверов.*

*Коммит `135fdbd` (135fdbd01177e247d7a78d346d3777745ab9ab9d), все цитаты дословные. Место происшествия: `pytoniq/liteclient/balancer.py`, строки 100–276.*

Нашему сыщику докладывали: в конторе pytoniq служит бюро под вывеской `LiteBalancer` — детективное агентство, которое следит за десятками лайтсерверов, расспрашивает их, вычисляет отстающих и решает, кому доверить очередное дело. Агентство почтенное, клиенты — вся сеть. Сыщик запросил досье. Прочитав его, он заказал у содержателя гостиницы второй газовый рожок — читать такое вполсвета опасно для рассудка.

---

## СЕНСАЦИЯ ПЕРВАЯ: АРХИВНОСТЬ УСТАНАВЛИВАЕТСЯ ЖРЕБИЕМ

Вопрос, от которого зависит половина расследований сети: хранит ли лайтсервер всю историю блокчейна, от сотворения мира? Бюро решает вопрос методом, достойным цирка на улице Стрэнд. Досье, строка 107:

```python
    @staticmethod
    async def check_archive(peer: LiteClient):
        try:
            blk, _ = await peer.lookup_block(wc=-1, shard=-2**63, seqno=random.randint(1, 1024))  # as ton-http-api does, but maybe need to ask the first block. todo
            return True
        except LiteClientError:
            return False
```

Вникните, милостивый читатель: вместо того чтобы спросить у подозреваемого самый первый блок мастерчейна — улику, которую не подделаешь, — сыщик бюро тянет из мешка случайный номер от 1 до 1024 и спрашивает: «А вот этот блок вы, часом, не помните?» Помнит — значит архивный. Не помнит — вон из картотеки. Приписка в протоколе честна до слёз: «as ton-http-api does» — мол, не мы первые, у соседнего бюро тот же мешок. А следом, почерком, дрожащим от нерешительности: «but maybe need to ask the first block. todo». Возможно, следовало бы спросить первый блок. Возможно. Когда-нибудь. Todo.

Отдельной строкой сыщик заносит соседнюю улику, строку 100: если подозреваемый вдруг перестал быть архивным, бюро называет это `almost impossible case` — «почти невозможный случай». В Лондоне, где детективы верят в почти невозможное, сыщику нашему известно, чем это кончается.

## СЕНСАЦИЯ ВТОРАЯ: ПРОСТОГУБЕРНАТОР ИЗМЕРЯЕТ ВРЕМЯ В ДНЯХ

Бюро ведёт табель: сколько миллисекунд каждый лайтсервер тратит на ответ. Успешный ответ записывается честно — строка 268:

```python
                resp = await peer_meth(*args, **kwargs)
                self._update_average_request_time(ind, (time.time_ns() - s) // 10**6)  # provide milliseconds
```

Наносекунды поделили на миллион — получили миллисекунды. Арифметика безупречна. Но вот подозреваемый не ответил в срок. Строки 270–271:

```python
            except asyncio.TimeoutError:
                self._update_average_request_time(ind, self.timeout * 10**6)  # provide milliseconds
```

Остановитесь и перечитайте. Таймаут задан в секундах (десять, по протоколу). Бюро умножает десять секунд на миллион — получает десять миллионов — и заносит в табель под грифом «provide milliseconds». Миллисекунд, с позволения сказать. Десять миллионов миллисекунд — это десять тысяч секунд, то есть примерно два часа сорок минут за один промах; а при одиночном проступке среднее арифметическое в табели сразу же составляет полные сто шестнадцать дней «среднего времени ответа». Один раз не дождался — и клеймо на сто шестнадцать дней, поделённое на число последующих добрых дел. Та же хирургия повторена на строке 276 для лайтсервера, осмелившегося ответить словом «timeout».

Разбирательство устанавливает: в ту же картотеку, строкой 181, попадает и норма для ещё не допрошенных — `self.timeout * 1000`, миллисекунды честные. Итого в одном реестре соседствуют миллисекунды, микросекунды, притворяющиеся миллисекундами, и тишина. Контора сортирует подозреваемых по этому реестру, то есть по смеси трёх мер длины. Сыщик, бывало, видел отчёты скоморохов; такого — не видел.

## СЕНСАЦИЯ ТРЕТЬЯ: КОНСЕНСУС ПО СЧИТАЛОЧКЕ

Кульминация досье — кабинет, где бюро вычисляет «консенсусный блок»: последний блок, который сеть признала наверняка. Строки 222–227:

```python
    def _find_consensus_block(self):
        self._update_mc_seqnos()
        seqnos = sorted(self._mc_blocks.values(), reverse=True)
        if not seqnos:
            return 0
        return seqnos[len(seqnos) * 2 // 3]  # block that knows at least 2/3 liteservers
```

Протокол гласит: отсортировать высоты блоков по убыванию и взять элемент с номером «две трети от числа сыщиков». Комментарий клянётся: это блок, который знают «at least 2/3 liteservers» — не менее двух третей. Сыщик наш, человек аккуратный, пересчитал на пальцах туманного вечера: из трёх осведомителей берётся третий по счёту, то есть блок, который знают все трое; из тридцати — двадцать первый, то есть блок, который знают двадцать один. Везде — две трети плюс один. Бюро требует кворум строже, чем само о том докладывает, и делает это с невозмутимостью счетовода, прибавляющего лишнюю гинею к каждому счёту «для верности». Двойка в числителе, тройка в знаменателе, целочисленное деление — и никакого суда над тем, почему не так и не этак. Каббала двух третей, признанная канцелярией математикой.

## ХРОНИКА МЕЛКИХ ПРОИСШЕСТВИЙ

*Отдел почты.* Досье, строки 453–456: одно исходящее письмо (`raw_send_message`) бюро отправляет сразу в `_k` контор, где `_k = 4 if len(self._alive_peers) < 12 else len(self._alive_peers) // 3` — четырём адресатам минимум, трети живых — по максимуму. В прошлых выпусках газета ловила почтамт mytonctrl на тройной отправке; здесь, с позволения сказать, целая почтовая орава. Сеть, впрочем, такую рассылку одобряет — но редакция обязана констатировать: эпидемия множественной отправки перекинулась с одной конторы на другую.

*Отдел канцелярии.* Строка 76: чтобы уравнять счёт в списке дел, бюро изготавливает фиктивное поручение — `async def f(): return connected` — и подшивает в общую папку. Сыщик доложил: бумага исполнена неукоснительно, содержания в ней нет.

*Отдел вывесок.* Строка 176: пришедшему не по адресу клиенту велено отвечать `raise BalancerError(f'Use start_up()')` — f-строкой, в коей нечего подставлять. Мелочь, но в доме, где всё построено на аккуратности, такие мелочи — трещины в фасаде.

## ВЕРДИКТ РЕДАКЦИИ

Скажем по совести: бюро `LiteBalancer` — заведение полезное. Оно следит за живыми и мёртвыми, гоняет отстающих, раскидывает дела по силам и в общем-то не даёт сети запутаться. Но в архивах его покоятся: жребий вместо вопроса о первом блоке, табель, где миллисекунды меряются сутками, и кворум, считаемый по считалочке «две трети от чего попало». Газета напоминает читателю: через это бюро проходит добрая половина запросов к сети TON. Туман над Темзой, как обычно, в курсе.
