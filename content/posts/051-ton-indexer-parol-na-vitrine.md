## ДЕЛО О КЛЮЧЕ, ПРИКЛЕЕННОМ К КОМАНДЕ

Лондон утонул в тумане, мостовая блестела, а газовый рожок у редакции сипел, словно ему поручили охранять банк, но забыли убрать вывеску с комбинацией. Сыщик «Вечернего Валидатора» получил папку из конторы [toncenter/ton-indexer](https://github.com/toncenter/ton-indexer) — индексатора, который раскладывает события TON по полкам PostgreSQL, Redis и прочих машинных подвалов.

На витрине лежала инструкция для запуска. Не секрет из истории коммитов, не случайный фрагмент теста и не записка в черновом каталоге. В публичном README штатный пример предлагает создать файл с паролем базы данных, причем пароль уже напечатан в команде. Викторианский банк мог бы выставить табличку: «Сейф за этой дверью, код — ниже».

Место происшествия: репозиторий [toncenter/ton-indexer](https://github.com/toncenter/ton-indexer), коммит [`5f7ae0e`](https://github.com/toncenter/ton-indexer/commit/5f7ae0e06615f5f8033cf52e57c1f40e74256fec), файл [`README.md`](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md), строки [38–49](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L38-L49). Цитата сверена с содержимым файла на этом коммите.

Протокол, файл [`README.md`](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md), строки [38–49](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L38-L49):

```bash
# Set PostgreSQL password
mkdir private
echo -n "My53curePwD" > private/postgres_password

# Pull images and start the stack
docker compose pull
docker compose up -d
```

## ПЕРВЫЙ СЛЕД: СЕКРЕТ ПЕЧАТАЕТСЯ В ПАМЯТКЕ

В блоке на строках [39–49](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L39-L49) описан запуск PostgreSQL. Читателю дают не отвлеченную схему, а последовательность действий для поднятия стека. Рядом стоит комментарий `# Set PostgreSQL password` — указание ясное, как звон колокола над туманным Сити.

Строка [40](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L40) создает каталог `private`. С виду это уже похоже на осторожность: отдельная комната, не парадный зал, место для чувствительных вещей.

Но строка [45](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L45) ломает всю интригу: `echo -n "My53curePwD" > private/postgres_password`. Пароль не предлагается придумать, не подставляется из защищенного хранилища и не отмечается как пример, который надо немедленно заменить. Он уже готов, аккуратно набран и направлен прямо в файл.

Газовый рожок кашлянул. Каталог назвали `private`, но комбинацию от него оставили на центральной странице конторы. Это не тайник, а комната с бархатной занавеской вместо стены.

## ВТОРОЙ СЛЕД: ФАЙЛ ДЛЯ СЕРЬЕЗНОГО СТЕКА

Сыщик не станет преувеличивать: одна строка README сама по себе не доказывает, что пароль дает доступ к чужой базе. Перед нами инструкция локального запуска, а не заявление о действующих учетных данных. Но контекст делает улику сочнее.

На строках [47–49](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L47-L49) сразу после записи пароля предлагается скачать образы и поднять стек через Docker Compose. Значит, напечатанная комбинация не лежит в музейной витрине отдельно от механизма. Она готовит файл, который затем участвует в реальном сценарии запуска сервисов.

Коммит [`5f7ae0e`](https://github.com/toncenter/ton-indexer/commit/5f7ae0e06615f5f8033cf52e57c1f40e74256fec) носит будничное имя `Refactor docker-compose deployment and README.md (#256)`. Никакого `add-example-password`, никакого предупреждения `replace-this-before-production`: реформа развертывания пришла вместе с паролем, который выглядит достаточно правдоподобно, чтобы его скопировали не глядя.

В этом и состоит главный фокус. Плохой пример обычно выдает себя строкой `TODO` или словами `CHANGE_ME`. Здесь же `My53curePwD` изображает готовую защиту. Имя пытается быть паролем, число пытается быть цифрой, а вся сцена пытается выглядеть как инструкция для настоящего сервера.

## ТРЕТИЙ СЛЕД: «PRIVATE» НЕ РАВНО «СЕКРЕТНО»

Каталог `private` на строке [40](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L40) может создать у новичка ложное чувство безопасности. Но имя папки — не средство шифрования и не хранилище секретов. Оно лишь говорит оболочке, куда положить файл.

На строке [45](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L45) оболочка получает обычную команду перенаправления. Она записывает известную строку в файл. В самой цитате нет генератора случайного значения, запроса пароля у оператора или ссылки на переменную окружения.

Даже если этот пароль задуман только для локального стенда, README не подчеркивает границу между учебной комнатой и производственным залом. А соседняя памятка на строках [47–49](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L47-L49) уже зовет Docker Compose поднимать целый стек. Новичок копирует блок, видит зеленый ход команд и может решить, что вопрос закрыт.

Редакция не станет называть строку [45](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L45) доказанным взломом. Но она доказывает другое: публичная инструкция раздает фиксированный пароль как часть штатного запуска PostgreSQL. Для демонстрационного стенда это неудачный пример. Для любой среды, которую кто-то по ошибке сочтет боевой, — готовая ловушка.

## ВЕРДИКТ СЫЩИКА

[toncenter/ton-indexer](https://github.com/toncenter/ton-indexer) — полезная контора, а не шайка ночных грабителей. Но коммит [`5f7ae0e`](https://github.com/toncenter/ton-indexer/commit/5f7ae0e06615f5f8033cf52e57c1f40e74256fec) оставил на витрине файла [`README.md`](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md) строку [45](https://github.com/toncenter/ton-indexer/blob/5f7ae0e06615f5f8033cf52e57c1f40e74256fec/README.md#L45), где пароль `My53curePwD` выдается без стука и допроса.

Приговор прост: для примера генерируйте значение на месте или явно пишите `CHANGE_ME`, а перед запуском требуйте заменить его. Каталог с именем `private` не спасает пароль, который уже напечатан в публичном README. Газовый рожок настаивает: секрет должен быть секретом хотя бы до того, как его положили в файл.
