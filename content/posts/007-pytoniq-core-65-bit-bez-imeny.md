# 📰 Вечерний Валидатор

**№ 7.** *Лондон. Туман нынче лезет под двери, как повестка. Сыщик наш уже побывал в конторе pytoniq — читатель помнит выпуск № 4, сыскное бюро `LiteBalancer` с его жребием и арифметикой. Нынче сыщик спускается этажом ниже, в самый фундамент: в пакет `pytoniq-core`, где отливают ячейки, сверяют хеши и — внимание, милостивый читатель — проверяют доказательства подлинности блоков. То есть в ту самую комнату, где рождается доверие.*

## СЕНСАЦИЯ ПЕРВАЯ: ПОЛЕ БЕЗ ИМЕНИ В СВИДЕТЕЛЬСТВЕ МАСТЕРЧЕЙНА

Первым делом сыщик вскрыл досье на разбор `McStateExtra` — свидетельства о состоянии мастерчейна, бумаги, без коей не строится ни одно дело. [`pytoniq_core/tlb/block.py`, строки 565–573](https://github.com/yungwine/pytoniq-core/blob/0b7adf9895b85a76a5ce5356d5621e8fd2e980fe/pytoniq_core/tlb/block.py#L565-L573):

```python

        flags = ref.load_uint(16)

            raise BlockError(f'McStateExtra deserialization error expected flags <= 1, got: {flags}')
        validator_info = ValidatorInfo.deserialize(ref)

        after_key_block = ref.load_bool()
        ref.load_bits(65)  # TODO why ?
```

Читатель, переведите дух. Канцелярия идёт по свидетельству строго по строкам: флаги — сверены, валидаторы — опрошены, старые блоки — перечитаны, булев знак — принят. А затем — шестьдесят пятая строка протокола: **проглотить шестьдесят пять бит и не спрашивать, чьи они**. Приписка на полях, почерком мастера: `TODO why ?` — «зачем? Неизвестно. Когда-нибудь разберёмся».

Справка редакции: шестьдесят пять бит — это не пыль под верстаком. Это ровно шестьдесят четыре плюс один: целый хеш-слиток с булевой печатью, стоящий посреди самой охраняемой бумаги сети. В кодексе TL-B этому полю имя положено, и догадливый читатель его найдёт; но канцелярия предпочла не гадать по кодексу, а глотать на веру. Глотает, между прочим, всякий раз, когда кто-либо в питоновском Лондоне спрашивает у сети: «Что нынче в мастерчейне?» Сеть отвечает. Контора читает. Шестьдесят пять бит проходят мимо окна, не назвавшись, — и все делают вид, что так и надо.

## СЕНСАЦИЯ ВТОРАЯ: АЛГОРИТМ, КОТОРЫЙ ЕЩЁ НЕ НАСТОЯЩИЙ

Глубже по коридору — кабинет проверки доказательств, `pytoniq_core/proof/check_proof.py`. Именно здесь контора решает, какие валидаторы уполномочены подписать блок, прежде чем поверить его подписи. Дело деликатное: ошибёшься в составе суда присяжных — и приговор вынесет толпа прохожих. Протокол заседания, строки [165–176](https://github.com/yungwine/pytoniq-core/blob/0b7adf9895b85a76a5ce5356d5621e8fd2e980fe/pytoniq_core/proof/check_proof.py#L165-L176):

```python
    if is_mc:
        if ccv_conf.shuffle_mc_validators:
            # TODO
            pass
        return list(vset.list.values())[:count]
    # TODO true algorithm
    nodes = []
    for i in range(count):
        node = vset.list[i + vset.total]
        node.weight = 1  # shardchain validator lists have all weights = 1 ?
        nodes.append(node)
    return nodes
```

Сыщик перечитал трижды при свете рожка. Пункт первый: если кодекс сети велит **перетасовать** валидаторов мастерчейна — `shuffle_mc_validators` — кабинет честно заносит в протокол `# TODO` и делает `pass`. То есть ничего. Тасовка отменяется по причине: потом. Пункт второй, для шардов, подписан ещё душевнее: `# TODO true algorithm` — «истинный алгоритм будет позже». А пока вместо истинного алгоритма — приём из уличной игры в три карты: берутся первые `count` имён из списка, и каждому вручается вес в единицу, с припиской вопросительным знаком: «shardchain validator lists have all weights = 1 ?» — «вроде бы у всех вес один?»

Вникните, милостивый читатель: это не лавка на Тотенхэм-Корт-роуд, это нотариальная контора, заверяющая доказательства. И на печати её выгравировано: «алгоритм временно ненастоящий, веса выдаются по слуху». Доверие к блокам, говорит нам канцелярия, покоится на трёх китах: TODO, pass и вопросительном знаке.

## ХРОНИКА МЕЛКИХ ПРОИСШЕСТВИЙ

*Отдел приёма посетителей.* В криптографической прихожей, [`pytoniq_core/crypto/keys.py`, строки 51–55](https://github.com/yungwine/pytoniq-core/blob/0b7adf9895b85a76a5ce5356d5621e8fd2e980fe/pytoniq_core/crypto/keys.py#L51-L55), сыщик застал дворецкого за любопытной службой:

```python
def mnemonic_to_entropy(mnemo_words: List[str], password: Optional[str] = None):
    # TODO: implement password
    sign = hmac.new((" ".join(mnemo_words)).encode(
        'utf-8'), bytes(0), hashlib.sha512).digest()
```

Функция принимает пароль — дверь распахнута, визитёра приглашают войти, — а затем молча не использует его. Ни словом, ни знаком. Клиент, передавший пароль, получает ту же самую энтропию, что и клиент без пароля, и уходит довольный, не подозревая, что его секрет побывал в прихожей, разулся и был тихо выставлен за дверь. Дворецкий лишь отметил в журнале: `TODO: implement password`. Пароль будет реализован. Когда-нибудь. А пока визитная книга чиста, а хеши — одинаковы.

## ВЕРДИКТ РЕДАКЦИИ

Скажем по совести: контора `pytoniq-core` — из тех, что редакция уважает. Ячейки отлиты ровно, код читается как роман, и виновные опять подписаны собственной рукой: «why ?», «true algorithm», «implement password». Но протокол есть протокол: в свидетельстве мастерчейна гуляет поле без имени, состав присяжных для проверки доказательств набирается по ненастоящему алгоритму, а пароль принимается к сведению и отправляется восвояси. Туман над фундаментом, как обычно, всё видел — и нынче сгустился ровно на шестьдесят пять бит.
