*Коммит [`90046e0`](https://github.com/ton-blockchain/mytonctrl/commit/90046e0) ([ton-blockchain/mytonctrl](https://github.com/ton-blockchain/mytonctrl)), ветка master, все цитаты дословные. Место происшествия: [`mytoncore/output.py`](https://github.com/ton-blockchain/mytonctrl/blob/90046e0/mytoncore/output.py#L50-L115), строки 50–115.*

## СЕНСАЦИЯ: ГОСПОДИН, СОБИРАЮЩИЙ JSON ИЗ ОШИБОК

Разбирательство показало: в конторе имеется переписчик по имени `tlb_to_json`. Его служба — превращать многословные ответы lite-client'а (сии TL-B-схемы, с позволения сказать) в приличный словарь. Занятие почтенное. Метод — с позволения сказать, нет.

Сперва переписчик грубо меняет скобки на фигурные — `(` на `{`, `)` на `}`, — затем окружает слова кавычками, посимвольно, пошагово, в три приёма («Add " to strings (step 1)», «step 2», «step 3» — канцелярия ведёт протокол). А далее происходит сцена, от которой у нашего сыщика потемнело в глазах:

```python
    # set comas
    while True:
        try:
            data = json.loads(text)
            break
        except json.JSONDecodeError as err:
            if "Expecting ',' delimiter" in err.msg:
                text = text[:err.pos] + ',' + text[err.pos:]
            elif "Expecting property name enclosed in double quotes" in err.msg:
                text = text[:err.pos] + '"_":' + text[err.pos:]
            else:
                raise err
```

Вникните, милостивый читатель: переписчик не знает грамматики собственного языка. Он подсовывает лист судье `json.loads` и ждёт приговора. Судья говорит: «здесь не хватает запятой» — переписчик вклеивает запятую ровно в указанную букву и подаёт лист снова. Судья говорит: «здесь положено имя свойства в кавычках» — вклеивается `"_":`. И так по кругу, `while True`, пока судья не смилуется. Комментарий над этим каббалистическим кругом гласит просто: «set comas» — запятые, с позволения сказать, помещены в кому.

Отрицательные числа, дроби, значения с пробелами внутри — всё это для переписчика terra incognita: любая цифра с минусом остаётся без кавычек, и круг вправления запятых начинается заново. Тонкий механизм держится не на понимании формата, а на текстах сообщений об ошибках — на том, что английская фраза «Expecting ',' delimiter» не изменится никогда.

## ВЕРДИКТ

Парсер, выведенный из показаний собственных падений. Сыщик заносит в протокол: `output.py:103` — хирургия вслепую, анестезия — `try/except`, прогноз — неутешительный. Конторе полагалось бы один раз выучить грамматику TL-B, а не переспрашивать судью про каждую запятую.
