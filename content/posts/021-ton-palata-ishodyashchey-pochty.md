# 📰 Вечерний Валидатор

**№ 21.** *Лондон. Туман нынче наведён так густо, что почтальоны сортируют письма на ощупь — и, надо признать, попадают. Наш корреспондент продолжает обход ядра [ton-blockchain/ton](https://github.com/ton-blockchain/ton): газета уже побывала в похоронном бюро (выпуск № 20), в архиве без посетителей (выпуск № 19) и у «очень глупого вектора» (выпуск № 4). Нынче — палата исходящей почты валидатора, [`validator/impl/validate-query.cpp`](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp): учреждение, которое сверяет каждое письмо, покинувшее город, с записью в очереди. Десять гербов на реестре, десять формуляров в уставе. Сыщик поднёс газовый рожок к реестру — и обнаружил, что шестой герб не нарисован, а написан словами. Словами «???».*

*Место происшествия: репозиторий [ton-blockchain/ton](https://github.com/ton-blockchain/ton), коммит [`3d478cb`](https://github.com/ton-blockchain/ton/commit/3d478cbde854be03a18ab2a59f8fc3c565cf7d14) (master от 17.08.2026). Файлы: [`validator/impl/validate-query.cpp`](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp), [`crypto/block/block.tlb`](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/crypto/block/block.tlb). Все цитаты дословные.*

## СЕНСАЦИЯ ПЕРВАЯ: ГЕРБ ПО ИМЕНИ «???» И ТАНЕЦ С ТРИНАДЦАТЬЮ ПОПОЛАМ

Церемония приёма письма начинается с опознания герба. Палата читает первые биты формуляра — и получает номер. А дальше, читатель, начинается хореография, строки [3442–3448](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3442-L3448):

```cpp
  if (tag == 12 || tag == 13) {
    tag /= 2;
  } else if (tag == 20) {
    tag = 8;
  } else if (tag == 21) {
    tag = 9;
  }
```

Осмыслите эти па. Формуляр с гербом двенадцать — делим пополам, будет шесть. Формуляр с гербом тринадцать — делим пополам, будет шесть же: в арифметике палаты тринадцать пополам — это шесть, и никаких остатков, остаток сметён под ковёр. Герб двадцать перекрашивается в восемь, герб двадцать один — в девять. Зачем эта пляска с бубнами, отчего двенадцать и тринадцать — родня, а двадцать — восемь, — устав не сообщает; устав сообщает другое. Строки [3449–3452](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3449-L3452):

```cpp
  // mode for msg_export_{ext,new,imm,tr,deq_imm,???,deq/deq_short,tr_req,new_defer,deferred_tr}
  static const int tag_mode[10] = {0, 2, 0, 2, 1, 0, 1, 3, 0, 2};
  static const char* tag_str[10] = {"ext", "new", "imm",    "tr",        "deq_imm",
                                    "???", "deq", "tr_req", "new_defer", "deferred_tr"};
```

Реестр гербов, читатель. Десять позиций. Позиция ноль — «ext», позиция один — «new», позиция пять — «???». Не «unknown», не «reserved», не пустая рамка на стене — а три вопросительных знака, внесённые в официальную опись типов исходящих сообщений всей сети. Сыщик сверился с гербовником [`crypto/block/block.tlb`](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/crypto/block/block.tlb), строки [217–237](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/crypto/block/block.tlb#L217-L237): девять формуляров носят имена, десятый — не существует вовсе. Герб пять, `$101`, — это просто начало чужого герба, набросок, из которого вырастают `new_defer$10100` и `deferred_tr$10101`; сам по себе он не бывает никогда. Палата держит в реестре строку для формуляра, который невозможен по уставу, — и называет её «???». Выпуск № 12 уже писал о типографии вопросительных знаков в этом городе; теперь вопросительный знак получил персональное место в геральдике.

А теперь присядьте, читатель, ибо следующая строка — из тех, ради которых издаётся газета. Когда герб не подошёл, палата выдаёт отказ, строки [3453–3456](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3453-L3456):

```cpp
  if (tag < 0 || tag >= 10 || !(tag_mode[tag] & mode)) {
    return reject_query(PSTRING() << "OutMsgDescr corresponding to " << m_str[mode] << "queued message with key "
                                  << out_msg_id.to_hex(352) << " has invalid tag " << tag << "(" << tag_str[tag & 7]
                                  << ")");
```

Вглядитесь в конец: `tag_str[tag & 7]`. Реестр — десять имён, а печать оттискивается по номеру «tag и семь». Отложенное письмо, герб восемь, в отказе будет названо «ext» — внешним. Отсроченный транзит, герб девять, — будет назван «new». Палата, уличив письмо в несоответствии, подписывает акт чужим именем. Не из злого умысла, читатель: из привычки. Маска `& 7` — рудимент эпохи, когда гербов было восемь; когда в 2024 году, в коммите [`0daee1d8`](https://github.com/ton-blockchain/ton/commit/0daee1d8875e52e6463acce9dfe5a9f9fc43e19d) («Merge message dispatch queue», 27 июня 2024-го), реестр расширили до десяти и дописали «???», — печать пересчитать забыли. Новые формуляры прибыли, новые имена вписали, а штамп остался старый, восьмеричный. Сыщик занёс в протокол: «учреждение ведёт реестр десяти гербов при восьмигранной печати; отказы на гербах восемь и девять заверяются именами чужих гербов; шестой герб зовётся „???"; тринадцать пополам есть шесть».

## СЕНСАЦИЯ ВТОРАЯ: СЛОВАРЬ ИЗ ЧЕТЫРЁХ ПРИСТАВОК

Как палата называет свои режимы работы, сыщик узнал ещё до гербов, — и записал с наслаждением. Строки [3429–3434](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3429-L3434):

```cpp
  int mode = old_value.not_null() + new_value.not_null() * 2;
  static const char* m_str[] = {"", "de", "en", "re"};
  auto out_msg_cs = out_msg_dict_->lookup(out_msg_id + 96, 256);
  if (out_msg_cs.is_null()) {
    return reject_query("no OutMsgDescr corresponding to "s + m_str[mode] + "queued message with key " +
                        out_msg_id.to_hex(352));
```

Здесь прекрасно всё, разбирайте по слоям. Строка [3429](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3429): режим вычисляется сложением двух булевых — «старое письмо есть» плюс «новое письмо есть, помноженное на два». Бухгалтерия из двух монет, дающая режимы ноль, один, два, три. Строка [3430](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3430): словарь палаты — `{"", "de", "en", "re"}`. Не слова, читатель, — приставки. Палата экономит буквы и склеивает речь из обрубков: к основе «queued» приклеивается «de», «en» или «re» — и в отказе выходит «dequeued message», «enqueued message», «requeued message». Контора владеет английским языком методом типографского наборного кассы: одно слово храним, остальные дожимаем. И строка [3431](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3431) — изящество над изяществом: ключ к реестру очереди отыскивается приёмом `out_msg_id + 96, 256` — к адресу прибавляют девяносто шесть бит и читают двести пятьдесят шесть. Письмо лежит не по адресу, а за девяносто шесть бит от него. Сыщик видел в Лондоне конторы, живущие через три дома от вывески; но чтобы адрес на конверте был лишь отправной точкой для вычисления — такова здешняя почта.

И когда склейка срабатывает, выходит протокол вроде строк [3436–3438](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3436-L3438): «EnqueuedMsg ... has been changed in the OutMsgQueue, but the key did not change» — «письмо в очереди изменилось, но ключ не изменился». Осмыслите жалобу: палата обвиняет письмо в том, что оно стало другим, оставшись на том же месте. В городе, где туман каждое утро становится другим, оставаясь туманом, это обвинение звучит почти как зависть.

## СЕНСАЦИЯ ТРЕТЬЯ: ПИСЬМО, В КОТОРОМ НЕТ ПИСЬМА

Венец ночи — формуляр под номером тринадцать, тот самый, что делится пополам. В гербовнике он записан так, [`crypto/block/block.tlb`](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/crypto/block/block.tlb), строки [227–229](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/crypto/block/block.tlb#L227-L229):

```
msg_export_deq_short$1101 msg_env_hash:bits256
    next_workchain:int32 next_addr_pfx:uint64
    import_block_lt:uint64 = OutMsg;
```

Сравните с соседями: каждый порядочный формуляр несёт `out_msg:^MsgEnvelope` — ссылку на конверт с письмом. `msg_export_deq$1100`, строка [225](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/crypto/block/block.tlb#L225), несёт конверт. `tr_req`, строка [230](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/crypto/block/block.tlb#L230), несёт конверт. А `deq_short` несёт `msg_env_hash:bits256` — отпечаток конверта. Двести пятьдесят шесть бит тени вместо самого конверта. Письмо, в котором записано, что письмо было. Палата откровенна в этом пункте до изящества, строки [3458–3459](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L3458-L3459):

```cpp
  bool is_short = (tag == 6 && (out_msg_cs->prefetch_ulong(4) &
                                1));  // msg_export_deq_short does not contain true MsgEnvelope / Message
```

«Does not contain true MsgEnvelope / Message» — «не содержит настоящего конверта / письма». Сыщик перечитал дважды: в уставе самого большого почтамта сети существует разряд депеш, про которые заранее известно, что настоящего письма в них нет. Есть отпечаток, есть адрес следующего переулка (`next_workchain`, `next_addr_pfx`), есть время ввоза — всё, кроме письма. И заметьте, как распознают такую депешу: герб делённый пополам (шесть) плюс один бит, вычитанный из первых четырёх, — `prefetch_ulong(4) & 1`. Настоящесть письма в этой палате определяется младшим битом.

Летопись приговора: формуляр учреждён коммитом [`cf97f48c`](https://github.com/ton-blockchain/ton/commit/cf97f48cd74a7033a0e0613285da26227b7076c1) от 7 апреля 2020 года, с характерным названием «error handling in lite client, speed up message dequeue in blocks» — «обработка ошибок в лёгком клиенте, ускорение выемки сообщений». Ускорение состояло в том, что письмо перестали таскать в депеше; стали таскать его отпечаток. Шесть лет город живёт с почтой, в которой часть сум вскрывать не требуется — нечем. Туман над Темзой, сам являющийся депешей без письма, проникается.

## ХРОНИКА МЕЛКИХ ПРОИСШЕСТВИЙ

*Отдел невозможного, филиал.* Входящая почта не отстаёт от исходящей. Приёмник входящих депеш, тот же файл, строка [4051](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L4051): `return reject_query(PSTRING() << "InMsg with key " << key.to_hex(256) << " has impossible tag " << tag);` — «входящее письмо имеет невозможный герб». Заметьте разницу в тональности: исходящему письму с невозможным гербом выдают «invalid tag» с именем из реестра, а входящему — сразу «impossible». К чужим письмам палата строже, чем к своим.

*Отдел вопросительных знаков.* Почерк «???» — фамильный. Строка [551](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L551): `// ??? impossible` — комментарий, в котором сначала сомневаются, потом констатируют невозможность. И строка [7460](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L7460): `// config:key_block?ConfigParams -> checked in compute_next_state() and ???` — «проверено в compute_next_state() и ???». Проверено там, и ещё неизвестно где. Место второй проверки занимает вопросительный знак — семь лет, с «initial commit» [`c2da007f`](https://github.com/ton-blockchain/ton/commit/c2da007f4065e2520e0d948b146e0fb12fa75751), как и строка [551](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L551), и «impossible tag» строки [4051](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L4051). Вопросительный знак в этом городе — самая долговечная разновидность документации.

*Часовая будка.* И чтобы читатель не ушёл без улыбки: в той же палате ведут учёт транзакций тика и тока, строки [5970–5973](https://github.com/ton-blockchain/ton/blob/3d478cbde854be03a18ab2a59f8fc3c565cf7d14/validator/impl/validate-query.cpp#L5970-L5973): `bool is_tock = (td_cs.prefetch_ulong(4) & 1);` — четыре бита читаются ради одного, младшего, который решает, тик сейчас или ток, — и дальше отказ подписывается `(is_tock ? "tock" : "tick")`. Часовой механизм всей сети, читатель, заводится одним битом из четырёх. Газета уже писала о часовой палате acton (выпуск № 18); в ядре часы скромнее — всего два положения, зато каждое с отказом, если при часах обнаружится письмо: «tock transaction ... has an inbound message». Тикать — можно, получать письма — нельзя.

## ВЕРДИКТ РЕДАКЦИИ

По справедливости — и газета строга к справедливости — палата исходящей почты работает. Герб «???» не встречается в природе: прибор `get_tag` читает пять бит у новых формуляров и пятёрки не выдаёт никогда; несуществующий тип охраняется тем надёжнее. Перекошенная печать `tag & 7` обманывает лишь в отказах, которые город отвергает оптом. Депеша без письма — не упущение, а экономия, документированная прямо в уставе. Всё это не уязвимости; всё это — канцелярия. Но почерк канцелярии газета фиксирует: город, в котором основание мира может измениться «внезапно» (выпуск № 20), ведёт исходящую почту реестром из десяти гербов, где шестой — три вопросительных знака; делит тринадцать пополам без остатка; склеивает слова из приставок «de», «en», «re»; и штампует отказы восьмигранной печатью по десятигранному реестру. Письма доходят — сеть живёт, читатель, — но когда-нибудь, в час тумана, какое-нибудь отложенное письмо получит отказ, подписанный именем «ext», и сыщик будет первым, кто скажет: мы писали. Туман над Темзой, у которого нет ни герба, ни отпечатка конверта, лишь подтянулся к окну палаты — посмотреть, как там поживает «???».
